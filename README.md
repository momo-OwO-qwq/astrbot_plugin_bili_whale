# astrbot_plugin_bili_whale ｜ 养鱼刷B站

> 一个会按**生物钟**替你刷 B 站的 AstrBot 插件：自己搜、**读字幕原文**判断、写一份日报和**两本日记**；值得的东西才会在评论区 **@ 你**，并把摘要推到 **AstrBot 已配置的消息平台**（可选再加 **B 站私信**）。
>
> 不是「定时任务 + 关键词搜索」，是**窗口内随机醒 + 偏好 + 克制**：每天只醒一两次，筛几条、深读两三条，**每天最多分享 3 条**；人格直接使用 AstrBot 里设定的人格。

这个插件把两个 DSH 插件合到了一起，用 Python 为 AstrBot 重写：

| 来源 | 拿来的东西 |
| --- | --- |
| [dsh-bili-scroll](https://github.com/c1overzz/dsh-bili-scroll) | 每天搜关键词 → **读字幕原文** → 写 Markdown 日报 → 挑值得的在评论区 @ 你；`### BV号` 日报格式；搜索/字幕/评论的 WBI 接口经验；提示词红线 |
| [dsh-bili-whale](https://github.com/Alterssss/dsh-bili-whale) | 生物钟（窗口内随机醒、30% 概率今天不看、最少间隔）；人设；两本日记；读/写/分享配额；412 熔断与请求节流 |

详细署名与两份原始 MIT 许可证见 [`NOTICE.md`](NOTICE.md) 和 [`LICENSES/`](LICENSES/)。

## 它做什么

- **扫码登录**：`/bili 登录` 直接在聊天里发二维码，手机 B 站扫完自动写 cookie；不用手抄 SESSDATA。
- **自己醒**：在你设定的窗口里随机一个时刻醒来（不是整点），两次之间至少隔 N 分钟；**30% 概率今天不想看**（但它仍会写日记、报备）。
- **真读内容**：按关键词搜近期视频（可排序/翻页），或关键词留空时刷**账号首页推荐流**；让模型从候选里挑几条，再逐条读 **官方字幕 + 热评 + 弹幕热区**。
  - 不是看标题猜内容：**没有字幕证据时，代码强制最多给「可以看」**。
- **写日报**：`reports/YYYY-MM-DD.md`，每条单独一段、第一行固定 `### BV号`，带档位和理由。
- **写两本日记**：一本《给主人的信》，一本只给自己的日记。
- **人格用 AstrBot 的**：默认直接读取 AstrBot 当前会话/默认人格；也可以在插件配置里指定某个人格 ID，或切回插件自定义人设。
- **多平台推送**：可以把摘要同时推到 AstrBot 里已配置的多个平台/会话（QQ、Telegram、飞书…），在目标会话发 `/bili 订阅` 即可加入；`/bili 推送` 查看清单。
- **B 站私信推送**（可选）：额外把 300 字内的摘要私信给 owner；需要第二个 B 站号且双方互关，每天最多 3 条，受写预算/冷却/熔断限制。
- **克制地分享**：可选在视频评论区发一条 **@ 你** 的评论；受评分、理由、每天 ≤3 条、同视频 7 天、写冷却、**发布前检查（去 AI 味/防撞车）**等硬限制。
- **发布前检查**：发前拦开头八股、和自己历史评论太像、和该视频热评太像；命中重写一次，仍不过就不发，并记进 `comments.md` 台账。
- **自然语言入口**：正常聊天里模型知道本机有 B 站能力，可调用只读工具；写工具（发评论、发私信、写记忆）默认关闭。
- **随时可用**：`/bili 现在刷`、`/bili 看 BV…`、`/bili 搜 …` 不必等生物钟。

## 它**不会**做什么

- ❌ 不会读画面、抽帧、转写：**只读文字**（字幕/热评/弹幕）。没有字幕轨的视频通常只能按简介判断。
- ❌ 不会给陌生人发私信、不会群发、不会监听/回复 B 站私信；私信只用于把摘要发给配置的 owner。
- ❌ 不会发动态、收藏、投币、关注、直播互动。
- ❌ 不会回复别人的评论 / 楼中楼（只在自己分享的视频下发一条顶层评论）。
- ❌ 不会批量操作、多账号、绕风控、抓全站数据。
- ❌ 默认不会自动分享；打开「自动发送」后评论才不再逐条确认。
- ❌ 不会把 cookie 或私聊内容写进日报/评论/日志。

> 它用的是**你自己的账号**。所以默认值很保守：少说、看准了再说。

## 安装

前提：**AstrBot 4.5.7 – 4.x**、Python 3.10+。插件只依赖 `aiohttp`（AstrBot 自带，`requirements.txt` 里也写了一份）。

```bash
# 1) 放进 AstrBot 的插件目录，目录名用 astrbot_plugin_bili_whale
cd AstrBot/data/plugins
git clone https://github.com/momo-OwO-qwq/astrbot_plugin_bili_whale.git astrbot_plugin_bili_whale

# 2) 在 AstrBot WebUI → 插件 里点「重载插件」
#    或者重启一次 AstrBot
```

> ⚠️ **目录名不要带连字符**。AstrBot 会按目录/模块名加载插件；仓库目录如果叫
> `astrbot-bili-whale`，请先 `mv astrbot-bili-whale astrbot_plugin_bili_whale` 再放进 `data/plugins/`。
> 目录名和 `metadata.yaml` 里的 `name` 一致最省事；通过 WebUI 从仓库安装时，AstrBot 会自动按 `name` 建目录。

装好后在 WebUI 插件列表里能看到「养鱼刷B站」。**第一次用先做这几件事**：

1. 在私聊或管理员会话发 **`/bili 登录`**，用手机 B 站扫码；扫完自动写 cookie。
2. 填 **关注关键词**（留空 = 刷首页推荐流），把「作息窗口」改成你希望它醒来的时间段。
3. 在每个想接收推送的 AstrBot 会话发一次 **`/bili 订阅`**（可多个平台/群）；再发 **`/bili 体检`** 确认登录态、人格和推送目标。
4. 想用 B 站私信推送再去配置里打开 `push.bili_dm.enabled`，填另一个号的 UID，并让双方互关。

### 登录

**方式 A：扫码（推荐）** —— 在聊天里发 `/bili 登录`，插件会发一张二维码图片；用 B 站 App 扫，手机上点「确认登录」，插件自动写 cookie 并回你账号信息。二维码 3 分钟有效，过期再发一次即可。图片发不出去时消息里会带二维码链接。

**方式 B：手动 cookie（扫码不灵时）** —— 插件配置 → B 站账号填：

1. 浏览器登录 `bilibili.com`；
2. **F12 → Application（应用）→ Cookies → https://www.bilibili.com**；
3. 复制 `SESSDATA`、`bili_jct`、`buvid3`。

> `SESSDATA` 是 **HttpOnly**，JavaScript 读不到；用 `document.cookie` 抄会缺件。WebUI 的 `secret` 只负责遮住显示，不会加密配置文件；cookie 以明文存在 AstrBot 的配置目录里，请自己保管好。

## 配置

所有配置都在 **WebUI → 插件 → 养鱼刷B站 → 配置**，由 `_conf_schema.json` 生成。

设置页按「B站账号 → 生物钟 → 内容 → 人格 → 产出 → 分享 → 推送 → 自然语言 → 请求保护 → 权限」分组；同类项合并，旧版「日报 / 日记」两组已并成「产出」，旧配置自动迁移。

### 生物钟

| 项 | 默认 | 说明 |
| --- | --- | --- |
| 启用自动刷 | 开 | 关掉后只能手动 `/bili 现在刷` |
| 作息窗口 | `20:00-24:00` | 可写多段：`12:00-14:00,20:00-24:00`；`24:00` 表示午夜 |
| 每天最多醒几次 | 1 | 0 = 不自动醒 |
| 今天不想看的概率 | 0.3 | 掷到就只写日记、不刷视频 |
| 两次唤醒至少隔 | 10 分钟 | 窗口里排不下就少醒一次 |
| 手动刷最多几条 | 3 | `/bili 现在刷` 只挑这么多，不占自动额度 |
| 手动刷冷却 | 10 分钟 | 防手滑狂点、防烧 token |
| 一轮超时 | 20 分钟 | 超时中止；防止模型/网络卡死 |

### 内容

| 项 | 默认 | 说明 |
| --- | --- | --- |
| 视频来源 | 自动 | 有词搜索、没词推荐；也可强制只用关键词/只刷推荐 |
| 关注关键词 | DeepSeek Harness 等 | 一行一个；最多用前 6 个 |
| 搜索排序 | 最新 | 最新 / 播放 / 弹幕 / 综合 |
| 搜索翻页 | 2 | 每页约 20~30 条；越多请求越多 |
| 排除关键词 | 空 | 标题里出现就跳过（广告/切片/搬运…） |
| 只看最近几天 | 7 | |
| 每轮深读几条 | 3 | 深读 = 字幕 + 热评 + 弹幕 + 模型总结，越多越贵 |
| 最短/最长时长 | 60s / 7200s | |
| 优先字幕语言 | `ai-zh` | B 站 AI 字幕需要登录 cookie |
| 读弹幕热区 | 开 | 弹幕只作辅助，不能单独支撑「值得看」 |

### 人格 / 人设

默认 `persona.source = astrbot`：**直接用 AstrBot 里设定的人格**。

- `persona_id` 留空：跟随推送目标会话生效的人格；没有会话级设置就用 AstrBot 默认人格；
- `persona_id` 指定某个 ID：固定用那个人格；
- `persona.source = custom`：改用插件自己的 `bot_name` / `call_user` / `call_self` / `人设正文`；
- AstrBot 人格正文最多取 4000 字；取不到时自动退回自定义人设/中性提示词。

> 插件自己的三句「角色名/称呼/自称」只在 `source = custom` 时参与；用 AstrBot 人格时不会强加「小鲸」这个名字。

### 分享

| 项 | 默认 | 说明 |
| --- | --- | --- |
| 允许评论分享 | 关 | 总开关；关掉后 `/bili 分享`、确认和自动发送都不执行 |
| 自动发送（不再逐条确认） | 关 | 打开后，到点刷、`/bili 现在刷`、`/bili 分享` 都直接发；关闭时只生成预览 |
| 手动刷也自动发送 | 开 | 只在自动发送开启时生效；关掉后 `/bili 现在刷` 只读不发 |
| 最低评分 | 13 / 20 | 低于不发 |
| 每天最多 | 3 条 | 与上游 whale 一致 |
| 同视频间隔 | 7 天 | 按 BV 号判重 |
| 理由至少 | 8 字 | 说不清为什么值得就不发 |
| 评论长度 | 40 字 | 15–200；越短越像人，默认 40 |
| 发布前检查 | 开 | 拦开头八股、和历史评论/该视频热评太像；命中重写一次，仍不过不发 |

> 打开「自动发送」后：到点刷、`/bili 现在刷`（可用下一项关掉）、`/bili 分享 BV` 都会直接发评论，不再要 `/bili 确认`。
> 仍然保留硬限制：评分、理由、每天 ≤3、同视频 7 天、写冷却、发布前检查、发送后匿名复查。
> 想只看预览：发 `/bili 分享 BV… 预览`；关闭自动发送时则始终先预览。
> 旧版 `share.mode` 会自动迁移成上面三个开关，不需要手动改。

### 权限

| 项 | 默认 | 说明 |
| --- | --- | --- |
| 群聊里只有管理员能刷/分享/改推送 | 开 | 会动账号或花钱的指令（刷、分享、确认、订阅、退订、推送、登录、状态、体检、版本、重载、重置计划）在群聊里只允许 AstrBot 管理员；私聊不受限。管理员名单在 AstrBot 主配置的 `admins_id` 里 |

### 请求保护

| 项 | 默认 |
| --- | --- |
| 请求间隔 | 1500 ms（低于 300ms 会被强制按 300 算） |
| 读 | 600/时 · 3000/天 |
| 写 | 12/时 · 30/天 |
| 写冷却 | 120 秒 |
| B站私信 | 3/天（另受写预算/冷却约束） |
| 撞 412 / 429 / 风控码 | 自动熔断 5 / 10 / 20 / 30 分钟 |

**新号别调大。** 默认值是按「刚创的小号」定的。

### 产出（日报 + 日记）

旧版的「日报」「日记」两组已合并为「产出」；升级时会自动迁移旧值，旧分组在配置里保留但隐藏。

| 项 | 默认 | 说明 |
| --- | --- | --- |
| 日报写多细 | 完整 | 完整 / 薄版 / 不写 |
| 推送时附完整日报 | 关 | 目标多时注意刷屏 |
| 写两本日记 | 开 | 给主人的信 + 自己的日记 |
| 把日记也推给你 | 关 | 私密内容，默认不推 |
| 日记只在私聊查看 | 开 | 群聊里不展示日记 |

### 自然语言入口（LLM）

| 项 | 默认 | 说明 |
| --- | --- | --- |
| 启用自然语言能力 | 开 | 关掉后只用 `/bili` 指令 |
| 注入能力提示 | 开 | 让模型知道本机有 B 站能力，不会一脸懵 |
| 允许只读工具 | 开 | 搜索 / 看视频 / 评论 / 日记 / 状态 |
| 允许模型真实发评论 / 私信 | 关 | 打开后才注册写工具：发评论、发私信、写长期记忆 |
| 刷视频用的模型 | 跟随会话 | 可钉死便宜模型，只影响插件内部生成 |
| 工具结果字数上限 | 900 | 防止长内容撑爆上下文 |

### 长期记忆（LivingMemory）

不是每条视频都记。分数够高直接记，中等分数按概率记，模型觉得特别有意思也会记。

| 项 | 默认 | 说明 |
| --- | --- | --- |
| 启用记忆联动 | 开 | 需要安装并启用 LivingMemory；没装时自动跳过 |
| 每轮自动写一条观看记忆 | 开 | 同一天同一个视频不重复写 |
| 低于这个分数不记 | 13 | 和「值得看」的线一致 |
| 达到这个分数直接记 | 16 | 高光视频必进长期记忆 |
| 中等分数被记住的概率 | 0.35 | 分数在两者之间时按概率随机 |
| 「有意思」的打分门槛 | 0.8 | 模型读完后打的 0–1 有趣程度 |
| 每天最多写几条 | 3 | 防止把整轮结果都灌进长期记忆 |
| 写入的重要性 | 0.65 | 越高越不容易被遗忘 |
| 单条记忆最多多少字 | 500 | 超长截断 |

### 推送（AstrBot 平台）

| 项 | 默认 | 说明 |
| --- | --- | --- |
| `targets` | 空 | 一个目标一行，格式为 AstrBot UMO，如 `aiocqhttp:FriendMessage:123456`。最省事：在目标会话发 `/bili 订阅`，自动加入 |
| `on_wake` | 开 | 到点刷完是否主动推；手动 `/bili 现在刷` 总会回到触发会话 |

- 配了 `targets` 就发给**所有**目标；一个都没配时退回最后一次会话。旧版 `push.session` 会在升级时自动并进 `targets` 并隐藏。
- `/bili 退订` 只把**当前会话**移出目标；所有目标都移出后自动关闭 `on_wake`。
  B 站私信是独立开关，`退订` 不会自动关它；要关请到配置里关 `push.bili_dm.enabled`。
- `/bili 推送` 会列出 AstrBot 已加载的平台适配器、是否支持主动消息，以及当前目标。
- 平台是否支持主动消息由适配器决定（例如 QQ 官方 API 有主动消息限制）；不支持时发送会失败，日志里会有原因。

### B 站私信推送（可选）

| 项 | 默认 | 说明 |
| --- | --- | --- |
| `enabled` | 关 | 每轮摘要额外发一条 B 站私信 |
| `to_mid` | 空 | 收件人 UID，留空用 `account.owner_mid` |
| `max_per_day` | 3 | 每天最多私信条数；仍受全局写预算 12/时·30/天、120 秒冷却和熔断限制 |
| `on_manual` | 关 | `/bili 现在刷` 时也发私信 |

> ⚠️ B 站私信需要**第二个 B 站号**作为收件人：同一个号不能给自己发；双方必须**手动互相关注**（`attribute=6`）。
> 只有 `account.owner_mid` / `to_mid` 这一个人能收，不支持群发或陌生人。摘要压到 300 字以内，不带本机路径。

## 指令

| 指令 | 做什么 |
| --- | --- |
| `/bili` / `/bili 帮助` | 指令列表（也可用 `/养鱼`、`/鲸鱼`） |
| `/bili 登录` | 扫码登录：发二维码图片，手机确认后自动写 cookie |
| `/bili 状态` | 账号、作息、今天的计划、额度、模型、数据目录 |
| `/bili 现在刷` | 立刻刷一轮（不占自动额度；自动发送 + 手动刷自动开启时会直接评论） |
| `/bili 看 BV1xx…` | 看懂一条视频（字幕 + 热评 + 弹幕），也可以直接 `/bili BV1xx…` |
| `/bili 搜 关键词` | 搜 10 条视频（标题/BV/UP/播放/时长） |
| `/bili 日报 [YYYY-MM-DD]` | 看日报，默认今天 |
| `/bili 日记 [YYYY-MM-DD]` | 看两本日记；默认只在私聊可用 |
| `/bili 订阅` | 把当前会话加入 AstrBot 推送目标（可多平台/多群） |
| `/bili 退订` | 把当前会话移出推送目标 |
| `/bili 推送` | 列 AstrBot 已配置平台、是否支持主动消息、当前推送目标 |
| `/bili 体检` | cookie/SESSDATA 形态、登录态、写权限、模型、配额、调度器自检 |
| `/bili 版本` | 插件版本 + main.py 指纹 + 配置/数据路径 |
| `/bili 额度` | 今天的读/写/分享/B站私信额度与熔断状态 |
| `/bili 分享 BV1xx…` | 自动发送开启时直接发；关闭时生成预览。加「预览」两字只看不发 |
| `/bili 分享设置` | 查看/修改：允许分享、自动发送、手动刷也自动发送 |
| `/bili 确认` | 发送上一条预览（关闭自动发送时用；30 分钟内有效）；发出后会匿名复查评论区 |
| `/bili 取消` | 取消待确认的分享 |
| `/bili 重载` | 重连 B 站会话（改完 cookie 用；不改也能在下一轮自动重连） |
| `/bili 重置计划` | 清掉今天的计划，按新作息窗口重排（改完作息窗口后用） |

> 🔒 会动账号 / 花钱 / 改推送目标的指令（刷、分享、分享设置、确认、订阅、退订、推送、登录、体检、状态、重载、重置计划），
> 在**群聊里只允许 AstrBot 管理员**使用；私聊直接可用。读取类（看、搜、日报）不受限。

另外注册了这些 LLM Tool：

| 工具 | 权限 | 说明 |
| --- | --- | --- |
| `bili_capability` | 只读 | 能力说明 |
| `bili_account` / `bili_search` / `bili_comments` / `bili_diary` / `bili_status` / `bili_video_digest` | 只读 | 账号、搜索、评论、日记、状态、看懂视频 |
| `bili_post_comment` | 写，默认关 | 在某条视频下发真实评论（仍有发送后复查） |
| `bili_send_dm` | 写，默认关 | 给配置的 B 站收件人发私信 |
| `bili_memorize` | 写，默认关 | 写一条 LivingMemory 长期记忆 |

写工具需要打开 `llm.allow_write_tools`；群聊里只有管理员能用。没权限时模型会如实说明，不会假装已发送。

## 一轮到底发生了什么

1. **醒来**：生物钟从落盘的计划里取时间；重启不会重抽。
2. **搜**：按来源搜索（可排序/翻页）或刷账号推荐流，再按时长、排除词、30 天判重过滤，最多留 40 条。
3. **挑**：模型看标题/UP/播放/时长/简介挑最多 `deep_read` 条；模型不可用时按新鲜度 + 热度兜底。
4. **读**：逐条取官方字幕（WBI 签名，带时间戳）、热评、弹幕热区。
5. **判断**：模型给 `score/20`、档位、理由、一句话；**代码再兜底**：
   - 没有字幕 → 最高「可以看」；
   - 字幕只有署名/空白 → 当无字幕；
   - 什么都没读到（无字幕、无弹幕、热评 < 3）→ 跳过并计数。
6. **写**：日报 + 两本日记；日报每条第一行是 `### BV号`。
7. **分享**（可选）：取评分最高的一条，生成以 `@你的昵称` 开头的评论；先过发布前检查，再过分分享闸门后发出；**发出后用匿名评论区列表复查是否真的公开可见**，只有复查通过才算「已发」，并记入评论台账。
8. **推送**：摘要发到所有 AstrBot 目标（可选完整日报/日记）；若开了 B 站私信，再发一条 300 字内摘要给 owner。
9. **收尾**：计划标记完成；同一天还有次数就排下一次。

模型调用优先用 AstrBot 的 `llm_generate`，失败退回 `provider.text_chat`；两者都不可用时，仍会写一份**基于字幕/简介的兜底报告**，不会把整轮丢掉。

## 常见问题

**插件列表里没有「养鱼刷B站」**
检查目录名、`metadata.yaml` 的 `name`、以及 AstrBot 日志里有没有 import 错误；改完在插件页点「重载插件」。

**`/bili 体检` 说未登录**
优先直接发 **`/bili 登录`** 扫码；手动 cookie 的话，`SESSDATA` 过期或复制不完整，重新从 F12 复制三个字段。改完发 `/bili 重载`，不用重启 AstrBot。

**报「WBI 签名密钥缺失」**
`nav` 没返回完整的 `wbi_img`，通常是未登录或被限流。先确认登录态，等几分钟再试；不要连续重试。

**HTTP 412 / 风控码**
插件会自动熔断 5–30 分钟。**别硬顶、别连续点「现在刷」**。等熔断结束，或明天再看。B 站 412 是 IP 级限流，换接口救不了。

**视频没有字幕**
B 站 AI 字幕需要登录 cookie；有些视频只有硬字幕/没有字幕轨。插件会读热评和弹幕，但**不会假装看懂了**，最多给「可以看」。

**日报里没有某条视频**
可能被关键词/时长/排除词过滤、30 天内看过、或深读后判为「不值当」（这类默认不进日报）。

**分享后提示「接口已接受，但复查未通过」**
B 站可能返回 `code=0` 但评论仅自己可见/审核中（俗称被吞）。插件不会把它算成已发，也不会自动重发；稍后去视频页确认，或在 `/bili 额度` 看记录。`/bili 确认` 会显示 rpid 和原因。

**分享没发出去**
看 `/bili 额度` 和结果里的原因：评分不够、理由太短、今天 3 条用完、同视频 7 天内发过、写冷却没到、cookie 缺 `bili_jct`、或者昵称和 B 站不一致。手动模式必须 `/bili 确认`。

**收不到主动推送**
先 `/bili 订阅`；确认平台支持主动消息；检查 `push.on_wake`；`/bili 退订` 之后是不会推的。没有可用会话时插件只在日志里留一句。

**模型没配**
AstrBot → 服务提供商里配一个聊天模型。没有模型时插件仍能搜/读/写兜底报告，但不会有「为什么值得」的判断。

## 与上游的差异（重要）

- **没有画面理解**：上游 whale 会 ffmpeg 抽帧、scroll 会看封面/画面帧；本插件是**纯文字**，因为 AstrBot 各平台的图片输入能力和 ffmpeg 依赖差异太大。
- **没有本地转写**：没有 Whisper；没字幕就跳过或只按简介/评论判断。扫码登录已补上，不再必须手抄 cookie。
- **没有「AI 评论占比闸」和「沉默衰减」**：上游 whale 分享前会抽样评论判断是否像 AI、并根据你有没有互动降低额度；本插件用**评分 ≥13 + 理由 ≥8 字 + 每天 ≤3 + 同视频 7 天 + 预览确认**替代，规则更简单、可解释。
- **私信只用于推送**：不监听、不回复 B 站私信；只把 300 字内摘要发给配置的 owner，要求第二个号和互关。
- **没有"回复评论"监听**：不会去别人的评论下互动；只在自己分享的视频下发一条。
- **有预览确认选项**：关闭自动发送时先预览、`/bili 确认` 才发，这是比上游更保守的一层。
